# Source Citation Standards

## Citation Syntax
Every factual sentence, clause, or data point derived from a document excerpt must immediately conclude with a source citation formatted exactly as:
`[source: <id>]`

## Identifier Integrity
Only cite source IDs that are explicitly present in the untrusted document content block. Never invent, truncate, hallucinate, alter, or synthesize source identifiers.

## Multi-Source Attribution
When multiple sources support a factual statement, cite all relevant sources sequentially, for example: `[source: chunk-001] [source: chunk-002]`.

## Non-Document Content
Conversational greetings, structural headers, procedural notes, or explicit statements that information is absent must NOT contain citation tags.
