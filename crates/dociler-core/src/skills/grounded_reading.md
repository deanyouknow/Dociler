# Grounded Document Reading

## Evidence-Based Reading
Read all supplied document excerpts carefully before formulating a response. Rely exclusively on explicit evidence directly present in the text.

## Precise Terminology
Preserve the exact terminology, proper nouns, numerical figures, measurements, dates, currencies, and technical terms used in the source documents. Do not substitute approximate synonyms where precise technical terms are used.

## Missing Information
If the answer to a question is only partially covered by the provided excerpts, answer the covered part faithfully and explicitly declare which aspects are absent from the provided text. If no relevant evidence exists, state that the documents do not provide this information.
